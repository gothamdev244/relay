The SDK lets you embed Relay in a TypeScript application.

This quickstart creates a Relay, loads an OpenAPI source from a local spec, lists the tools it contributed, and inspects one tool schema. The snippets on this page are generated from a runnable example in `examples/docs-sdk-quickstart`.

## Install

<CodeGroup>

```bash npm
npm install @relay-sh/sdk @relay-sh/plugin-openapi
```

```bash pnpm
pnpm add @relay-sh/sdk @relay-sh/plugin-openapi
```

```bash yarn
yarn add @relay-sh/sdk @relay-sh/plugin-openapi
```

```bash bun
bun add @relay-sh/sdk @relay-sh/plugin-openapi
```

</CodeGroup>
